# Books Scraper

Проект собирает данные обо всех книгах учебного каталога

## Установка

Просто запустите главный ноутбук -> в первой ячейке сразу подтягиваются зависимости.
Единственное, могут возникнуть проблемы с pip -> его нужно до новой версии обязательно обновить.

## Библиотеки

- requests
- beautifulsoup4
- schedule
- pytest
